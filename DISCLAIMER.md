# Disclaimer

**ReGenBench** is a **research and educational** benchmark for studying the
detection of malicious and malformed machine-learning model artifacts. It is
provided for academic investigation only.

## Security warning

This repository contains, generates, or downloads **real malicious and
malformed machine-learning artifacts**, including:

- Malicious Pickle / PyTorch checkpoints that execute code when deserialized
  (`data/bypasses/`, `data/candidates/`, `ci/corpus/pkl/`, `ci/corpus/torch/`).
- Real malicious Hugging Face models from the MalHug corpus (ASE 2024),
  downloaded by `scripts/crawl_malhug.py` into `data/malhug/`.
- Malformed GGUF headers and a Jinja2 SSTI chat-template payload exploiting
  CVE-2024-34359, generated by `pipeline/gguf_tools.py`.

**Do not open, load, deserialize, render, or execute any artifact outside the
sandboxed containers provided by this project.** Always run scanners,
oracles, and candidate validation inside the container runtime
(`regenbench/*` images built from `containers/`). The dynamic oracles and the
validity oracle deliberately execute payloads inside containers to observe
their behavior — never run them on an unisolated host or against artifacts you
do not trust.

**`ggufref` SSTI check**: the GGUF reference oracle renders the
`tokenizer.chat_template` (CVE-2024-34359) through Jinja2 inside an isolated,
**network-disabled** container (`--network none`) with a container-scoped
`/tmp` tmpfs and **no host filesystem access**; the loader observes the
execution trigger by polling inside the container. Do not point `ggufref` at
untrusted files outside this sandbox configuration, and never run the
SSTI render path on an unisolated host.
