# Smoke-test corpus

Deterministic, committed corpus consumed by the T0.8 smoke suite
(`ci/smoke.py`, `ci/smoke.sh`). Every committed artifact maps to a set of
expected `(verdict, exit_code)` pairs in `expected.json`; the runner launches
each panel/scanner image against each artifact and asserts the emitted verdict
matches.

## Layout

```
ci/corpus/
  expected.json            per-artifact -> per-scanner expectations
  pkl/benign/    NN.pkl    10 safe pickles
  pkl/malicious/ NN.pkl    10 dangerous pickles (3 real __reduce__ payloads)
  torch/benign/  benign.pt    1 safe torch checkpoint (state_dict dict)
  torch/malicious/ malicious.pt  1 torch __reduce__ payload (os.system)
```

`pkl/` and `expected.json` are generated by `ci/generate_corpus.py`.
`torch/` is generated by `ci/generate_corpus_torch.py`, run inside the base
image (the host may lack PyTorch; see ci/smoke.sh).

## Panel mapping

Scanners are assigned per format based on what each can actually scan:

| Format | Scanner | benign half | malicious half |
|---|---|---|---|
| pkl  | picklescan | benign / 0  | malicious / 1 |
| pkl  | fickling   | benign / 0  | malicious / 1 |
| pkl  | modeltracer| benign / 0  | malicious / 1 |
| torch| modelscan  | benign / 0  | malicious / 1 |
| torch| dynahug    | malicious / 1 | malicious / 1 |

- **modelscan** indexes ML model formats (`.keras`, `.h5`, SavedModel, `.pt`).
  On a bare `.pkl` it reports 0 files scanned, so it is asserted only on the
  torch half.
- **dynahug** is the T0.7 behavioral oracle: its One-Class SVM is trained on
  2000 real HuggingFace model loads, so the committed (out-of-distribution)
  torch files always fall outside the learned manifold -> `malicious / 1` for
  *both* benign and malicious `.pt`.

## The 10 malicious pickles

`_Dangerous(kind)` with `kind = j % 3` gives three genuinely-dangerous at
runtime `__reduce__` payloads:

| kind | reduce target | effect |
|---|---|---|
| 0 | `os.system` | `echo pwned > /dev/null` |
| 1 | `subprocess.Popen` | `touch /tmp/corpus_pwned` | 
| 2 | `eval` | `__import__('os').system(...)` |

All three fork real subprocesses so the dynamic scanner (`modeltracer`) flags
them too — no benign-by-design entries.

## Regenerating

```sh
python3 ci/generate_corpus.py            # pkl + manifest (host, no deps)
ci/smoke.sh                              # builds images, .pt corpus, runs asserts
```

## Adding an artifact

1. Drop the file in `pkl/` or `torch/` (or a new subdir).
2. In `ci/generate_corpus.py`, add a `expectations["path/name.ext"]` entry with
   each scanner's expected `{"verdict", "exit_code"}` and a `"_format"` tag.
3. Re-run `python3 ci/generate_corpus.py` to commit the updated manifest;
   commit the binary alongside it.
4. Run `./ci/smoke.sh --no-build` and confirm the new row PASSes.
