## Container runtime decision

Docker is **not installed** on this host (Void Linux, runit). Podman 5.8.3 is installed
and fully functional, including the `podman-docker` docker-compat socket. Per this task's
decision, **Podman is the Docker-compatible runtime**: all T0.2–T0.7 images are built and
run with `podman build` / `podman run`, which consume the same Dockerfiles and offer the
same semantics. Fully-qualified registry names are required (e.g.
`docker.io/library/alpine:latest`) because unqualified-search registries are not configured
in `/etc/containers/registries.conf`.

### Runtime notes
- Rootless Podman; user `void` is in no docker-equivalent group and needs none (rootless).
- cgroup v2 active with `cpuset cpu io memory hugetlb pids rdma misc` controllers.
- To enable the docker-compat socket as a runit service (not required for this task):
  `sudo ln -s /etc/sv/podman-docker /var/service/`.
